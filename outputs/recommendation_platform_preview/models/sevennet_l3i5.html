description
Pre-training of SevenNet-0 on the M3GNet dataset (derived from Materials Project) covering 89 elements, using 5 interaction blocks with 128 scalars, 64 vectors, and 32 tensors, cutoff radius of 5 Å, Adam optimizer with initial learning rate 0.004, batch size 16, Huber loss with δ=0.01, force loss weight 0.1, stress loss weight 0.01, trained for 450 epochs.
PDF Section 5.1: full training details for SevenNet-0.
